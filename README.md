Vitals 2.0 — прототип PWA

Как поставить на iPhone иконкой на рабочий стол:
1. Выложить содержимое этой папки на любой HTTPS-хостинг
   (GitHub Pages, Netlify Drop — перетащить папку на app.netlify.com/drop, Vercel).
2. Открыть ссылку в Safari на iPhone.
3. «Поделиться» → «На экран Домой».
Приложение откроется во весь экран, без адресной строки, работает офлайн.
